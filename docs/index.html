Exact 64-byte padding

confirmed · software confirmed · RTL source

FIPS needs two blocks; RTL can skip the second

Message length 64 → pad to 128 bytes (msg block + 0x80/zeros/length). Software model ≡ hashlib. In sha256_unit.sv S_LOAD, when m_idx==63 and byte_last, FSM jumps to S_W0 with final_block=1 and never enters S_PAD80.
